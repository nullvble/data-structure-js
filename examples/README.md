# Примеры из реальных задач

Каждый пример — самостоятельный файл: полезный класс или функция, которую можно скопировать
в свой проект, и демонстрация с выводом. Все примеры детерминированы и прогоняются в CI,
поэтому всегда соответствуют текущей версии библиотеки.

```bash
npm run examples                    # запустить все
npm run examples -- rate-limiter    # один пример (по началу имени файла)
```

## Бэкенд

| Пример | Задача | Структуры |
|---|---|---|
| [rate-limiter.ts](./rate-limiter.ts) | Ограничение частоты запросов к API (скользящее окно), ответ 429 и `Retry-After` | `Deque` |
| [async-cache.ts](./async-cache.ts) | Кэш для асинхронных функций: LRU + TTL + склейка одновременных запросов | `LRUCache` |
| [job-scheduler.ts](./job-scheduler.ts) | Отложенные задачи с приоритетами и повторами с экспоненциальной задержкой | `BinaryHeap` |
| [service-monitoring.ts](./service-monitoring.ts) | Скользящие метрики (среднее, p95, доля ошибок) и алерт при нарушении SLA | `CircularBuffer` |

## Как запустить пример в своём проекте

Примеры импортируют библиотеку так же, как вы: `import { … } from 'ds-kit-js'`.
Скопируйте файл, установите пакет и запустите через любой TypeScript-раннер:

```bash
npm install ds-kit-js
npx tsx rate-limiter.ts
```
